# Customer Churn Analysis using Microsoft Excel
![Customer Churn Dashboard](customer%20churn%20dashboard.png)

## Project Overview

This project analyzes customer churn data using Microsoft Excel. The objective is to identify patterns and factors contributing to customer churn and present the findings through an interactive dashboard.

The project covers the complete data analysis workflow, including data cleaning, exploratory data analysis, PivotTables, PivotCharts, slicers, dashboard creation, and business recommendations.

## Objectives

- Analyze customer churn behavior.
- Identify the customer segments with the highest churn.
- Determine whether customer inactivity influences churn.
- Compare churn across subscription plans, payment methods, regions, gender, and age groups.
- Provide actionable business recommendations.

## Key Business Insights

- Basic subscription customers recorded the highest number of churned customers.
- Adult customers experienced the highest churn.
- Longer periods of inactivity were associated with increased customer churn.
- Customer churn varied across payment methods and regions.
- Monthly spending differed across subscription plans.

## Recommendations

- Improve customer engagement for inactive users.
- Develop retention campaigns for Basic subscription customers.
- Monitor customers approaching long periods of inactivity.
- Improve customer support and customer experience.
- Investigate the reasons behind churn in high-risk customer groups.
